A parallel laboratory Job reported success but lost partition outputs because all eight workers wrote result.json in the same shared directory. Worker logs confirmed distinct input partitions but identical final paths, with no storage mount failures. A reviewed Indexed Job design used completion indices for distinct filenames and atomic writes with validated idempotent retries. An isolated run including a retried partition produced eight valid files and matching total record counts, and the pipeline now checks output completeness separately from exit status.
