Development simulator pods were evicted from one node after unrotated debug traces consumed several gigabytes of ephemeral storage and caused DiskPressure. Eviction events and filesystem inspection confirmed disk exhaustion rather than container memory pressure. After test pods stopped, the node owner recovered capacity using supported runtime cleanup, and the simulator was updated with trace retention caps and explicit ephemeral-storage requests and limits. A bounded repeat test stayed within budget without evictions, and the application failed cleanly when its output budget was reached.
