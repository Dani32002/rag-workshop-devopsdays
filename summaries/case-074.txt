A laboratory upgrade rehearsal rejected an Ingress manifest using an API version no longer served by the target cluster. Inspection identified networking.k8s.io/v1 requirements, including the current service backend structure and an explicit pathType for the intended /docs prefix route. The migrated manifest passed server-side dry run and root, nested, and nonmatching-path checks in the disposable rehearsal cluster. All release sources were updated, but the actual maintenance upgrade remained gated on other rehearsal checks and had not proceeded.
