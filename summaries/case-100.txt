A canary platform node image passed basic readiness but failed a rehearsal volume-mount test because dependency cleanup removed a host package required by the CSI node plugin. Comparison with the verified image confirmed the missing prerequisite while established nodes remained healthy. Wider promotion stayed stopped, the owner withdrew the candidate, retained failure evidence, and retired the isolated canary through the normal lifecycle workflow. Storage, networking, and workload checks became explicit promotion gates, and this release closed as rejected rather than repaired or successfully promoted.
