A laboratory controller lost API access after about an hour because its custom client cached the startup service account token beyond expiration. Expiry comparisons and mounted-file checks showed projected tokens rotated correctly on disk, but the client continued using the original value despite valid RBAC permissions. The custom authentication wrapper was replaced with a supported Kubernetes client configuration that rereads the token file. A soak test passed through two rotations with unchanged RBAC scope and audience and without introducing long-lived credentials.
