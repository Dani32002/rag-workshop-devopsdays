The sandbox importer Job in the moss namespace was OOMKilled when processing large generated files under a 256 MiB limit. Investigation found that the new implementation accumulated the entire file in memory, and a controlled sandbox run measured about 700 MiB of usage. A streaming implementation processed the same input below 180 MiB with identical output counts. Two large samples passed, reviewed resource settings retained a bounded limit, and a memory regression test was added.
