A development report-renderer Deployment in the willow namespace created no pods because admission rejected its memory requests. ReplicaSet events showed that an additional 2 GiB would exceed a 4 GiB namespace quota already accounting for 3 GiB. Load testing supported the requested resources, so the namespace owner removed an expired experiment through the approved cleanup workflow rather than understating the renderer's needs. Pod creation then succeeded and all replicas became ready without changing the renderer's resource contract.
