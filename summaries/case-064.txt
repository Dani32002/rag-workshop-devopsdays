Sandbox monitoring memory grew during load tests because a histogram label included every unique generated request identifier, creating unbounded series cardinality. Active-series growth tracked identifier count while the application itself remained stable. Reviewed instrumentation removed the per-request label and retained bounded route and status labels, producing a stable series count under the same load. Old series aged out under normal retention as memory pressure eased, route-level latency remained available, and sampled synthetic traces now support per-request inspection.
