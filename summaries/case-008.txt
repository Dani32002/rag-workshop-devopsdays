A tutorial pod in the larch namespace was rejected because its explicit 1 GiB memory request exceeded an automatically supplied 512 MiB limit. Inspection traced that limit to the namespace LimitRange, whose 2 GiB maximum and available quota allowed a suitable explicit limit. Following measurements near 800 MiB, the reviewed manifest retained the 1 GiB request and set a 1536 MiB limit. The pod was admitted and completed peak-load testing, and the tutorial now explains namespace resource defaults.
